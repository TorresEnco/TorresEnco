### 1. Shoe Store Inventory System

<a href="https://github.com/TorresEnco/shoe-store-inventory">
  <img src="https://img.shields.io/badge/Personal%20Project-087E8B?style=flat-square&logo=github&logoColor=white" alt="Personal project" />
</a>
<img src="https://img.shields.io/badge/Status-In%20Development-DAA520?style=flat-square" alt="In development" />

A web application designed to manage inventory and sales for a footwear store, with a mobile-first approach.

**Key features and contributions:**
- Independently designed and developed the application.
- Implemented product, variant, user, and sales management.
- Developed authentication mechanisms and sales detail records.
- Designed the system using Hexagonal Architecture to separate application responsibilities.
- Built a dashboard to support inventory and sales monitoring.

**Technologies:** React, Vite, TypeScript, Java, Spring Boot, PostgreSQL.

[View repository →](https://github.com/TorresEnco/shoe-store-inventory)
