## Featured Projects

### 01. Shoe Store Inventory System
**Inventory Management & Sales Core** · `Personal Project` · `In Development`

A mobile-first web application designed for comprehensive inventory tracking, variant control, and sales operations.

- Designed and built the solution independently with a domain-centric mindset.
- Applied **Hexagonal Architecture** (Ports & Adapters) to separate core business logic from framework dependencies.
- Implemented secure authentication, role permissions, and full sales auditing.
- Developed an administrative dashboard for real-time inventory and metrics tracking.

`Java` `Spring Boot` `PostgreSQL` `React` `TypeScript`

[View repository →](https://github.com/TorresEnco/shoe-store-inventory)
